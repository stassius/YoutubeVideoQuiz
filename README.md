# YouTube Local Nano Quiz

[English README](README_english.md)

Пользовательский TamperMonkey-скрипт, который создаёт викторину по расшифровке открытого YouTube-видео. Вопросы генерируются встроенной локальной моделью Chrome (Gemini Nano), без отправки транскрипта во внешний AI-сервис.

## Требования

- Актуальная версия Google Chrome для компьютера. Мобильные версии Chrome не поддерживаются.
- Не менее 22 ГБ свободного места на диске с профилем Chrome.
- GPU с более чем 4 ГБ VRAM либо CPU с 16 ГБ RAM и минимум 4 ядрами.
- Безлимитное интернет-соединение для первоначальной загрузки модели. После загрузки модель работает локально.
- Видео с доступной расшифровкой или автоматическими субтитрами.

## 1. Установка Tampermonkey

1. Установите расширение с [официального сайта Tampermonkey](https://www.tampermonkey.net/).
2. Убедитесь, что расширение включено в Chrome.

Если пользовательские скрипты не запускаются, откройте `chrome://extensions`, включите **Режим разработчика** и проверьте, что Tampermonkey разрешено выполнять пользовательские скрипты.

## 2. Установка скрипта с GitHub

Исходный код находится в [репозитории YouTubeVideoQuiz](https://github.com/stassius/YoutubeVideoQuiz).

### Прямая установка в Tampermonkey

Это самый простой способ, если нужен только готовый скрипт:

1. Откройте нужную версию: [русскую](https://raw.githubusercontent.com/stassius/YoutubeVideoQuiz/main/YouTube-Local-Nano-Quiz_russian.user.js) или [английскую](https://raw.githubusercontent.com/stassius/YoutubeVideoQuiz/main/YouTube-Local-Nano-Quiz_english.user.js).
2. Tampermonkey распознает файл с расширением `.user.js` и откроет страницу установки.
3. Проверьте название скрипта и нажмите **Установить**.

Если страница установки не открылась автоматически, скопируйте адрес страницы **Raw** и вставьте его в **Tampermonkey → Панель управления → Утилиты → Установить по URL**.

Адреса `@downloadURL` и `@updateURL` уже указаны в скрипте, поэтому Tampermonkey сможет проверять обновления непосредственно на GitHub.

Также [репозиторий](https://github.com/stassius/YoutubeVideoQuiz) можно склонировать через Git или скачать вручную через **Code → Download ZIP**. Русская версия называется `YouTube-Local-Nano-Quiz_russian.user.js`, английская — `YouTube-Local-Nano-Quiz_english.user.js`.

### Ручная установка скачанного файла

1. Откройте меню Tampermonkey и выберите **Панель управления**.
2. Нажмите кнопку создания нового скрипта (значок **+**).
3. Удалите стандартный шаблон редактора.
4. Откройте скачанный файл нужной языковой версии в текстовом редакторе и скопируйте всё его содержимое в редактор Tampermonkey.
5. Сохраните скрипт сочетанием `Ctrl+S` и убедитесь, что он включён.

## 3. Включение локальной модели Chrome

1. Откройте `chrome://flags/#optimization-guide-on-device-model`.
2. Установите значение **Enabled**.
3. Откройте `chrome://flags/#prompt-api-for-gemini-nano`.
4. Выберите **Enabled multilingual**. Если такого варианта нет, выберите **Enabled**.
5. Нажмите **Relaunch** или полностью перезапустите Chrome.
6. Откройте страницу YouTube и нажмите **Создать викторину**. Первый запуск инициирует загрузку Gemini Nano и может занять продолжительное время.

Проверить состояние можно на странице `chrome://on-device-internals`, вкладка **Model Status**.

## 4. Настройка числа вопросов

В начале скрипта найдите объект `CONFIG`:

```js
REQUIRED_QUESTIONS: 7,
OPTIONAL_QUESTIONS: 3,
```

- `REQUIRED_QUESTIONS` — число основных вопросов;
- `OPTIONAL_QUESTIONS` — число дополнительных сложных вопросов.

После изменения сохраните скрипт и перезагрузите вкладку YouTube.

Кнопка дополнительных вопросов управляется отдельным флагом:

```js
MORE_QUESTIONS_BUTTON: false,
```

Значение `true` показывает кнопку **Ещё вопросы**, `false` скрывает её.

## 5. Использование

1. Откройте обычную страницу просмотра YouTube-видео.
2. Дождитесь появления блока под описанием видео.
3. Нажмите **Создать викторину**.
4. Дождитесь чтения транскрипта и генерации вопросов. Длинные видео обрабатываются дольше: транскрипт разбивается на фрагменты и локально сжимается.
5. Выберите или введите ответ и нажмите **Проверить**.

Короткие текстовые ответы сначала сравниваются с эталонами локально. Если точного совпадения нет, их смысл дополнительно проверяет Gemini Nano.

## Ограничения

Gemini Nano — небольшая генеративная модель, а расшифровка YouTube может содержать ошибки распознавания речи. Поэтому викторина иногда может:

- неправильно понять термин;
- создать неточный или неоднозначный вопрос;
- выбрать неверный эталонный ответ;
- ошибиться при проверке свободного текстового ответа;
- пропустить некорректный вопрос и показать меньше настроенного количества.

Не используйте результат как единственный источник оценки знаний. Если вопрос, ответ или объяснение выглядят сомнительно, сверяйтесь с видео и учебными материалами. Для детей рекомендуется проверка викторины взрослым или преподавателем.

## Конфиденциальность

Скрипт читает расшифровку из открытой страницы YouTube и передаёт её встроенной модели Chrome. Удалённые AI API и переводчик не используются. Интернет всё же нужен YouTube, Tampermonkey и для первоначальной загрузки или обновления локальной модели Chrome.
