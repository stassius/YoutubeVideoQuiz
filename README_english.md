# YouTube Local Nano Quiz

[Russian README](README.md)

A Tampermonkey userscript that creates a quiz from the transcript of the open YouTube video. Questions are generated by Chrome’s built-in local model (Gemini Nano), without sending the transcript to a remote AI service.

## Requirements

- A current desktop version of Google Chrome. Mobile Chrome is not supported.
- At least 22 GB of free space on the drive containing the Chrome profile. This is Chrome’s eligibility requirement for built-in AI, not the size of Gemini Nano itself: the downloaded model uses considerably less space.
- A GPU with more than 4 GB of VRAM, or a CPU system with 16 GB of RAM and at least 4 cores.
- An unmetered internet connection for the model’s initial download. The model runs locally after downloading.
- A video with an available transcript or automatic captions.

## 1. Install Tampermonkey

1. Install the extension from the [official Tampermonkey website](https://www.tampermonkey.net/).
2. Make sure the extension is enabled in Chrome.

If userscripts do not run, open `chrome://extensions`, enable **Developer mode**, and make sure Tampermonkey is allowed to run userscripts.

## 2. Install the script from GitHub

The source code is in the [YouTubeVideoQuiz repository](https://github.com/stassius/YoutubeVideoQuiz).

### Direct installation in Tampermonkey

This is the easiest option if you only need the ready-to-use script:

1. Open the desired version: [English](https://raw.githubusercontent.com/stassius/YoutubeVideoQuiz/main/YouTube-Local-Nano-Quiz_english.user.js) or [Russian](https://raw.githubusercontent.com/stassius/YoutubeVideoQuiz/main/YouTube-Local-Nano-Quiz_russian.user.js).
2. Tampermonkey will recognize the `.user.js` file and open its installation page.
3. Check the script name and click **Install**.

If the installation page does not open automatically, copy the **Raw** page address and paste it into **Tampermonkey → Dashboard → Utilities → Install from URL**.

The script already contains `@downloadURL` and `@updateURL`, so Tampermonkey can check for updates directly on GitHub.

You can also clone the [repository](https://github.com/stassius/YoutubeVideoQuiz) with Git or download it using **Code → Download ZIP**. The English version is `YouTube-Local-Nano-Quiz_english.user.js`; the Russian version is `YouTube-Local-Nano-Quiz_russian.user.js`.

### Manual installation of a downloaded file

1. Open the Tampermonkey menu and select **Dashboard**.
2. Click the button for creating a new script (the **+** icon).
3. Delete the default editor template.
4. Open the downloaded language version in a text editor and copy all of its contents into the Tampermonkey editor.
5. Save with `Ctrl+S` and make sure the script is enabled.

### Updating the script

1. Open **Tampermonkey → Dashboard**.
2. Open the installed script and select **Check for updates** in its settings. The wording may vary slightly between Tampermonkey versions.
3. If no update is found, open the direct link for the desired language version above again and confirm the update or reinstallation.

## 3. Enable Chrome’s local model

1. Open `chrome://flags/#optimization-guide-on-device-model`.
2. Set it to **Enabled**.
3. Open `chrome://flags/#prompt-api-for-gemini-nano`.
4. Select **Enabled multilingual**. If that option is unavailable, select **Enabled**.
5. Click **Relaunch** or restart Chrome completely.
6. Open a YouTube page and click **Create quiz**. The first run starts the Gemini Nano download and may take a while.

You can check its state at `chrome://on-device-internals` under **Model Status**.

## 4. Configure the number of questions

Find the `CONFIG` object near the beginning of the script:

```js
REQUIRED_QUESTIONS: 7,
OPTIONAL_QUESTIONS: 3,
```

- `REQUIRED_QUESTIONS` controls the number of main questions.
- `OPTIONAL_QUESTIONS` controls the number of harder optional questions.

Save the script and reload the YouTube tab after making changes.

The additional-questions button has a separate flag:

```js
MORE_QUESTIONS_BUTTON: false,
```

Set it to `true` to show **More questions**, or `false` to hide it.

## 5. Usage

1. Open a standard YouTube video page.
2. Wait for the quiz panel to appear below the video description.
3. Click **Create quiz**.
4. Wait while the transcript is read and questions are generated. Long videos take longer because their transcripts are split into fragments and condensed locally.
5. Select or enter an answer and click **Check answer**.

Short text answers are first compared with reference answers locally. If there is no exact match, Gemini Nano additionally checks their meaning.

## Limitations

Gemini Nano is a small generative model, and YouTube transcripts may contain speech-recognition errors. The quiz may occasionally:

- misunderstand a term;
- create an inaccurate or ambiguous question;
- choose an incorrect reference answer;
- make a mistake when checking a free-text answer;
- skip an invalid question and show fewer questions than configured.

Do not use the result as the sole measure of knowledge. If a question, answer, or explanation looks doubtful, check it against the video and learning materials. Adult or teacher review is recommended when children use the quiz.

## Privacy

The script reads the transcript from the open YouTube page and passes it to Chrome’s built-in model. It does not use remote AI APIs or a translation service. Internet access is still required for YouTube, Tampermonkey, and the initial download or later update of Chrome’s local model.
